# E‑Pharmacy 💊🏥

**E‑Pharmacy** is a web platform that connects users with multiple pharmacies, allowing them to browse products, compare offers, and purchase medicines online. It provides a convenient way to access healthcare products while ensuring transparency and reliability.

## 🚀 Features

- **Pharmacy Catalog**: Browse a list of pharmacies with available products.
- **Product Pages**: Detailed view of each medicine with description, price, and pharmacy info.
- **Search & Filters**: Find products quickly by name, category, or pharmacy.
- **Authentication**: Register, log in, and manage your account securely.
- **Favorites**: Save products or pharmacies for easy access later.
- **Responsive UI**: Optimized for mobile and desktop devices.

## 🛠️ Tech Stack

- **Next.js 16 (App Router)** — modern React framework.
- **React Query (TanStack Query)** — data fetching and caching.
- **Axios** — HTTP client for API requests.
- **React Hook Form** — form handling with validation via Yup.
- **React Select** — customizable select inputs.
- **React Datepicker** — date selection component.
- **React Paginate** — pagination component.
- **TypeScript** — strict typing for reliable code.
- **CSS Modules** — component-level styling.
- **Zustand** — lightweight state management for global app state.
- **Vercel** — deployment and hosting platform.
